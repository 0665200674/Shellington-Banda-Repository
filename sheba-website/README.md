# SHEBA Website

Working website project for **SHEBA Integrated Brand & Digital Agency**.

## Current direction
- Premium
- Bold
- Corporate
- Primary audience: ambitious SMEs, without excluding larger organisations
- Integrated capabilities: Brand & Strategy, Creative & Advertising, Digital & Commerce, Technology & Systems

## Development
The current prototype is intentionally self-contained in `index.html` so the visual direction and information architecture can evolve quickly before we introduce a fuller asset/component structure.
